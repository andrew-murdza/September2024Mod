Snow Fortress saved world

Snapshot: November 24, 2026.
Minecraft 1.20.1 / Forge 47.4.22, using the September2024Mod modpack.

To restore:
1. Close Minecraft and use the compatible modpack described in release/README.txt.
2. Extract snow-fortress.zip into the Minecraft instance saves directory
   (run/saves for the development launcher).
3. Confirm saves/Snow Fortress/level.dat exists, then select Snow Fortress
   from the singleplayer world list. Extract into a fresh folder to keep
   any existing save intact.

This archive preserves all 180 saved-world files, including every saved
dimension, player data, world settings, datapacks, and per-world serverconfig.
Only the temporary session.lock is excluded; Minecraft recreates it.
The original save was left unchanged. No mod code or global config is included.

snow-fortress-manifest.json records every file and its SHA256 hash.
SHA256SUMS.txt records the archive hash. Every archived file was verified
against the original save after compression.
